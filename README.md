# معارف ✦

منصة عربية تفاعلية لتعلّم المعلومات العامة واختبارها، صُممت لتكون أساسًا لموقع ويب متجاوب وتطبيق جوال لاحقًا.

## ما يتضمنه الإصدار الأول

- واجهة عربية RTL متجاوبة للجوال والويب، بتصميم بصري مستقل ومؤثرات خفيفة وإيموجيات تعبيرية.
- أكثر من **10,000 سؤال وجواب** محليًا، موزعة على: العلوم، الجغرافيا، المعلومات الإسلامية، التاريخ، الأدب والفنون، الثقافة والسينما، التقنية، الرياضة، اللغة العربية، الطبيعة، والرياضيات.
- تدريب حر بلا وقت، اختبار معرفة، تحدي البرق، وتحدي يومي ثابت الأسئلة خلال اليوم.
- نظام نقاط ومستويات ونسبة دقة وتقدّم حسب الفئة، مع حفظ النتائج على الجهاز عبر `localStorage`.
- قسم مسابقات قابل للتوسع لاحقًا إلى غرف لعب ولوحات صدارة حقيقية.
- ملف PWA Manifest وخدمة Worker أولية تمهيدًا لتحويله إلى تجربة قابلة للتثبيت أو تغليفه كتطبيق جوال.

## التشغيل محليًا

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. لبناء نسخة إنتاجية:

```bash
npm run build
npm run preview
```

## هيكل المشروع

```text
src/
  App.jsx                 # الواجهة والمنطق التفاعلي
  styles.css              # التصميم المتجاوب والمؤثرات
  data/categories.js      # بيانات الفئات وألوانها
  data/questions.json     # بنك الأسئلة
public/
  manifest.webmanifest    # بيانات PWA
  sw.js                   # خدمة التخزين المؤقت الأولية
scripts/
  build_questions.py      # تحويل البنك النصي إلى JSON عند الحاجة
```

## التحويل إلى تطبيق جوال لاحقًا

أفضل مسار مقترح هو تغليف المشروع عبر **Capacitor** بعد تثبيت نسخة الويب. عند إضافة حسابات ومنافسات حقيقية، يمكن ربط المشروع بـ Supabase أو Firebase لتوفير:

- تسجيل المستخدمين.
- نتائج ولوحة صدارة مشتركة.
- تحديات وغرف خاصة.
- مزامنة التقدم بين الأجهزة.

## النشر على GitHub

تم تجهيز المشروع ليكون مستودع Git. بعد إنشاء مستودع عام باسم مثل `maaref` في حساب GitHub، نفّذ:

```bash
git remote add origin https://github.com/USERNAME/maaref.git
git branch -M main
git push -u origin main
```

> لا تُضف كلمات مرور أو رموز وصول GitHub داخل المشروع أو في الملفات العامة.
