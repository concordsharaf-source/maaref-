# معارف ✦

**معارف** تطبيق عربي RTL للمسابقات والمعلومات العامة. صُمّم بأسلوب Mobile First ليعمل كتطبيق PWA مستقل عند تثبيته، مع واجهة مستوحاة من تطبيقات Android الحديثة وقابلة للتغليف مستقبلًا عبر Capacitor.

## ما يتضمنه الإصدار الحالي

- واجهة تطبيق عربية كاملة RTL: شريط علوي عملي، شريط تنقل سفلي ثابت، بطاقات لمس كبيرة، ودعم Safe Area للشاشات الحديثة.
- أكثر من **10,000 سؤال وجواب** محليًا، موزعة على العلوم والجغرافيا والمعلومات الإسلامية والتاريخ والأدب والفنون والثقافة والتقنية والرياضة واللغة العربية والطبيعة والرياضيات.
- تدريب حر بلا وقت، اختبار معرفة، تحدي البرق، وتحدي يومي ثابت الأسئلة خلال اليوم.
- شاشة حل مركزة: رقم السؤال، شريط تقدم، خيارات كبيرة، تصحيح واضح، نقاط، انتقال تلقائي قابل للتخصيص وزر متابعة يدوي.
- شاشة نتائج تطبيقية تعرض النقاط والإجابات الصحيحة وغير الصحيحة والنسبة والوقت، مع مشاركة النتيجة عند توفر مشاركة النظام.
- نظام نقاط ومستويات ونسبة دقة وتقدّم حسب الفئة، محفوظ محليًا عبر `localStorage`.
- سجل يمنع تكرار السؤال للاعب حتى يعيد إتاحته يدويًا من الإعدادات.
- الوضع الداكن، حجم نص أكبر، وتقليل الحركة؛ تحفظ الإعدادات تلقائيًا على الجهاز.
- PWA قابل للتثبيت بتشغيل مستقل، Manifest عربي، أيقونات مناسبة، وService Worker لتخزين واجهة التطبيق محليًا للاستخدام دون اتصال بعد أول تحميل.
- لا توجد API أو Firebase أو حسابات مستخدمين أو قاعدة بيانات خارجية في هذه المرحلة؛ جميع بيانات الأسئلة والتقدّم محلية.

## التشغيل محليًا

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. لبناء نسخة إنتاجية:

```bash
npm run build
npm run preview
```

## هيكل المشروع

```text
src/
  App.jsx                 # منطق الجولات والحالة ومكونات واجهة التطبيق
  styles.css              # نظام التصميم المتجاوب والوضع الداكن وSafe Area
  data/categories.js      # بيانات الفئات وألوانها
  data/questions.json     # بنك الأسئلة
public/
  manifest.webmanifest    # بيانات تثبيت PWA
  sw.js                   # التخزين المؤقت لواجهة التطبيق
scripts/
  build_questions.py      # تحويل البنك النصي إلى JSON عند الحاجة
```

## التثبيت كتطبيق

يُثبّت معارف من قائمة المتصفح:

- **Chrome أو Edge على Android/Desktop:** اختر «تثبيت معارف» أو «إضافة إلى الشاشة الرئيسية» من القائمة.
- **Safari على آيفون وآيباد:** اختر زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

توجد هذه التعليمات أيضًا داخل صفحة **المزيد ← الإعدادات** في التطبيق، ولا يظهر زر تثبيت عائم داخل الصفحة الرئيسية.

## التحويل إلى Google Play لاحقًا

الواجهة لا تعتمد على حيل WebView أو مكونات سطح مكتب، وتستخدم عناصر لمس ومساحات آمنة مناسبة للتغليف. بعد تثبيت تجربة PWA، المسار المقترح هو تغليف المشروع عبر **Capacitor**. عند إضافة حسابات أو منافسات جماعية، يمكن ربط Supabase أو Firebase لاحقًا مع الحفاظ على منطق الجولات المحلي الحالي.
